豆包演示密钥模板
================

真实文件 `AISecrets.swift` 已加入 .gitignore，仅在本机与演示构建中保留真实值。
若仓库缺少 `AISecrets.swift`，新建 `DayGlyph/Services/AISecrets.swift`，内容如下，并填入真实 ARK API Key：

    import Foundation

    enum AISecrets {
        // 火山方舟 ARK API Key，形如 "ark-xxxxxxxx..."
        static let arkAPIKey = "PUT_YOUR_ARK_API_KEY_HERE"
    }

安全说明：按设计文档第 2 条，比赛演示版接受 API Key 可被提取的风险，该方案不得用于正式上架。
