# DayGlyph 第三轮情绪量化、Glyph 生成与核心 UI 设计

日期：2026-06-10

## 目标

第三轮解决三个相互关联的问题：

1. 情绪识别不能再被压缩为单一标签和笼统能量值。
2. Glyph 必须具有可解释、可复现、可混合的生成语法。
3. 今日、月历和详情页需要形成符合 iOS 26 的克制高级视觉，而不是依赖白色卡片堆叠。

本轮以支持 Foundation Models 的目标设备为前提。当前开发机的系统模型资格不影响模型接口、纯逻辑测试和固定演示数据验证。

## 情绪量化模型

`FoundationEmotionAnalyzer` 仍是主识别路径，但结构化输出改为：

- `valence`：`-1...1`，负向到正向。
- `arousal`：`0...1`，低唤醒到高唤醒。
- `dominance`：`-1...1`，失控到掌控。
- 12 个固定情绪锚点权重：平静、喜悦、感恩、释然、希望、激动、生气、焦虑、悲伤、疲惫、孤独、困惑。
- 主题、关键词、置信度和简短解释。

模型输出必须经过本地规范化：

- 所有数值截断到合法范围。
- 负权重变为 0，全部权重归一化为总和 1。
- 展示时取权重最高的 3 个锚点。
- 若总权重为 0，则使用“困惑”作为低置信度兜底。
- `arousal` 兼容原有 `energy` 语义，但新代码不再把能量当作完整情绪模型。

本地关键词分析器保留为系统不可用时的旧兼容路径，不作为本轮视觉生成逻辑或甲方演示依据。

## 模块化情绪印记

Glyph 由四层组成：

1. **边界**：闭合度、圆润度、偏心、厚度和结构稳定性。
2. **轨迹**：方向、曲率、开合、角度、振荡和视觉重心。
3. **核心**：大小、位置、实心程度和内外关系。
4. **节律**：数量、间距、长度、扩散和规律性。

连续维度负责基础结构：

- `valence` 控制色温、明暗、上扬/下沉和开放程度。
- `arousal` 控制密度、对比、节律数量和动势。
- `dominance` 控制边界强度、中心稳定、闭合程度和向外压力。

情绪锚点作为可叠加的形态算子：

- 平静：提高对称、圆润和低频节律。
- 喜悦：上扬、开放、轻度绽放。
- 感恩：增加包裹式次级弧线。
- 释然：打开边界并形成释放方向。
- 希望：提高向上轨迹和前方留白。
- 激动：增加受控放射与节律密度。
- 生气：压缩核心、提高棱角和向外冲力。
- 焦虑：增加偏心、高频振荡和节律不均。
- 悲伤：降低重心、收窄开口和降低对比。
- 疲惫：压低结构、减少节律并增加厚重感。
- 孤独：扩大核心周围负空间并减少陪衬元素。
- 困惑：引入有限的交叠轨迹和方向分叉。

seed 只允许产生受限微差异，例如 `±3°` 旋转、`±2%` 偏移和节律起始相位；不得改变主体语义。

## 核心 UI

视觉方向为“静默纸艺 × 染色玻璃”：

- 暖纸感浅色背景、深墨绿色正文、低饱和情绪环境光。
- Liquid Glass 只用于按钮、标签、选择态和导航交互层。
- Glyph 是页面唯一高对比视觉主角。
- 本轮只完整支持浅色模式，iPhone 优先；iPad 保持可用但不设计独立双栏。

### 今日页

- 输入态保留低门槛文本编辑。
- 生成完成后同页形态转换：编辑器收拢为文本摘要，Glyph 原位扩展。
- 生成仪式依次显示边界、轨迹、核心和节律，并触发一次成功触觉。
- 保存后仅大尺寸 Glyph 保留低幅、慢速微动；月历缩略图静止。
- 开启“减少动态效果”时，所有绘制与微动退化为淡入和交叉溶解。

### 月历

- 保留 7 列月历结构，移除每个日期的白色独立卡片。
- 有记录日期直接显示 Glyph 和轻微情绪色晕。
- 选中日期显示玻璃光环，并在网格下方展开当日摘要。
- 点击摘要进入详情页。

### 详情与解释

- 大 Glyph、日期、前两项情绪、主题和自然语言解释构成首屏。
- “为什么是这一划”默认折叠，展开后显示 VAD、前三项情绪权重，以及边界/轨迹/核心/节律的映射说明。
- 原文和删除操作保持现有能力。

## 数据与演示

- `DayEntry` 新增 VAD、情绪权重编码和分析版本字段，并提供默认值以兼容旧数据。
- 旧 `isDemo` 记录全部删除，替换为固定分析夹具，不再通过关键词分析器生成。
- 新演示月覆盖 12 个锚点、不同 VAD 象限和多种混合权重，确保月历能展示完整视觉范围。
- 非演示记录不删除；旧记录按兼容值展示，重新生成后升级到新模型。

## 验收标准

- 同一分析结果与 seed 生成完全一致的参数。
- 生气、焦虑和激动即使唤醒度接近，也必须因效价、掌控感和情绪算子呈现明显差异。
- 40pt 月历缩略图仍能区分主要结构，260pt 大图具有可见层次。
- 所有核心交互触控区域不小于 44pt，支持 Dynamic Type 和 VoiceOver 标签。
- iPhone 17 / iOS 26.5 完整构建、单元测试和 UI 启动测试通过。
